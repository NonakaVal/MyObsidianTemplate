
# Créditos e Atribuições

Este projeto reúne ideias, referências, recursos e contribuições de diferentes pessoas da comunidade Obsidian e do universo de Personal Knowledge Management (PKM).

Abaixo estão listadas as principais fontes que serviram de inspiração, referência ou base para o desenvolvimento deste projeto.

## Inspirações e Referências

### Vaults, Estruturas e Organização

- [Dusk Obsidian Vault](https://github.com/DuskWasHere/dusk-obsidian-vault) — Sistema de organização que combina os métodos PARA e Zettelkasten.
- [PARA Method — Forte Labs](https://fortelabs.com/blog/para/) — Método de organização de informações desenvolvido por Tiago Forte.
- [ACE para Organização, Pacote de Conhecimento (v1.0)](https://www.linkingyourthinking.com/) — Nic Milo & LYT. Referência para organização e estruturação de conhecimento.
- [The Ultimate Folder System: A Quixotic Journey to ACE](https://forum.obsidian.md/t/the-ultimate-folder-system-a-quixotic-journey-to-ace/63483) — Discussão sobre o desenvolvimento do sistema ACE.
- [Linking Your Thinking Resources](https://forum.obsidian.md/t/linking-your-thinking-resources/6177) — Coleção de recursos e materiais da comunidade LYT.

### Dashboards e Interfaces

- [Dashboard ++](https://github.com/TfTHacker/DashboardPlusPlus) — Plugin para criação de dashboards personalizados no Obsidian.
- [JournalCraft](https://github.com/TfTHacker/journal-craft-obsidian) — Sistema de organização e acompanhamento de diários.
- [JournalCraft — Toolbox for Thought](https://tfthacker.com/jco) — Documentação e apresentação do projeto JournalCraft.

### Escrita e Produção de Conhecimento

- [How to Write a Novel in Obsidian](https://pdworkman.com/write-book-with-obsidian/) — Referência sobre escrita de livros, templates e fluxos de trabalho no Obsidian.

### CSS e Personalização

- [Obsidian CSS Snippets — NonakaVal](https://github.com/NonakaVal/Obsidian-CSS-Snippets) — Coleção de snippets CSS para personalização da interface do Obsidian.
